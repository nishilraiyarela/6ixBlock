# Screenshots

Save final app screenshots in this folder before publishing the GitHub repository.

Use these file names so the main README screenshot grid works correctly:

- `light-feed.png`
- `light-map.png`
- `light-create.png`
- `light-activity.png`
- `light-profile.png`
- `dark-feed.png`
- `dark-map.png`
- `dark-create.png`
- `dark-activity.png`
- `dark-profile.png`

Recommended screenshot size: a phone portrait screenshot from Android Studio or a real Android device.
